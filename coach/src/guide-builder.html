ShapeShft Practice Guide Builder

Turn the guide text from your AI coach into a practice guide you can open on your phone, even without internet. Everything happens on this device. Nothing is uploaded.

How it works

  1. Ask your AI coach for an offline guide. For example: "Make me a 7-day offline practice guide." It replies with guide text in a box.
  2. Copy everything in that box and paste it below.
  3. Click Preview to check it, then Download guide.
  4. Open the downloaded file on your phone or computer. The Help folder explains how to move it to your phone.

Preview

This is how the guide will look. Links in the contents list may not move the preview, but they work in the downloaded file.

The guide text format (for the curious and for AI assistants)
Write thisYou get
Title: ... (first lines; also Subtitle:, For:, Date:, Level:, Time:)The guide's heading
# Day 1: Getting startedA section, listed in the contents
## Step 1A smaller heading
Plain linesA paragraph
- item or 1. itemA list
> "On a normal day, I would..."A sentence-starter box
! Stop somewhere safe before you read.A highlighted note
::: example ... :::Example wording, labeled "Example only. Use your own words."
::: closed Facts to check ... :::A section that opens when tapped (for recall practice)
::: open More ideas ... :::A tappable section that starts open
**bold**, *italic*, ---Bold, italic, a dividing line

Web links and HTML code are shown as plain text and never become active. The downloaded file contains no code of any kind.
