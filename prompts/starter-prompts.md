# ShapeShft starter prompts

Copy a prompt, paste it into your AI assistant, and change the parts in CAPITAL LETTERS. You do not need to write your own prompts. These work best in a project that has the ShapeShft instructions. If you are not using a project, attach `ShapeShft-AI-Instructions.md` to the chat first.

**Contents**

- Getting started: 1 Initial setup, 2 Start Career Discovery, 3 Update my Career Profile
- Resume Builder: 4 Tailor an application, 5 Revise an application, 6 Fix JSON that will not load
- Conversation Coach: 7 Start coaching, 8 Today's spoken practice, 9 Practice with a job, 10 Seven-day offline guide, 11 Prepare for an interview, 12 Questions to ask, 13 After an interview, 14 Compare opportunities, 15 Update my Practice Journal
- Keeping your work: 16 Start a new chat without losing anything

---

## 1. Initial setup

```
I am new to ShapeShft and to AI assistants. Please help me set it up one step at a time. Ask me what you need to know, wait for me to finish each step, and use simple language. I would like help with: RESUMES / PRACTICING TALKING ABOUT MY WORK / BOTH.
```

## 2. Start Career Discovery

```
Please start ShapeShft Career Discovery with me. I will share what I have. If I have nothing, start with a conversation. Ask me only a few questions at a time. My goal right now is: FOR EXAMPLE, FIND A WAREHOUSE MANAGER JOB.
```

Then paste or attach anything you have: an old resume, your LinkedIn profile text, job descriptions from past roles. All optional.

## 3. Update my Career Profile

```
I want to update my ShapeShft Career Profile. Here is what is new: DESCRIBE IT, FOR EXAMPLE A NEW CERTIFICATE, OR SOMETHING I REMEMBERED ABOUT A PAST JOB. Ask me anything you need to confirm it, then give me the complete updated career-profile.md file.
```

## 4. Tailor an application

```
Please tailor a resume and cover letter for this job. Check it against my career preferences first, and ask me about anything important that is missing from my profile.

PASTE THE COMPLETE JOB POSTING HERE
```

Tip: copy the whole posting, from the job title to the end. Postings disappear, so ShapeShft keeps a copy.

## 5. Revise an application

```
Please revise my application. Here is the current JSON from the Workbench (I may have edited it). Changes I want: DESCRIBE THE CHANGES. Return the complete JSON.

PASTE THE JSON FROM THE WORKBENCH LOAD TAB (COPY JSON BUTTON)
```

## 6. Fix JSON that will not load

```
The Resume Workbench will not load the JSON you gave me. The message says: PASTE THE ERROR MESSAGE. Please send the complete JSON again, corrected, in one code block.
```

## 7. Start Conversation Coaching

```
I want to start ShapeShft Conversation Coaching. I am not used to talking about my work out loud. Please explain how the practice works, ask me a few questions, and then give me a short first practice session I can do today.
```

## 8. Today's spoken practice

```
Give me today's spoken practice. I have ABOUT 15 MINUTES. I will practice WALKING / AT HOME. Use my Practice Journal to choose what to work on.
```

## 9. Practice with a specific job

```
Give me a spoken practice session based on the JOB TITLE job at COMPANY from my Job Library. Focus on: A TOPIC, FOR EXAMPLE TRAINING PEOPLE, OR "YOU CHOOSE".
```

If the job is not in your Job Library yet, paste the full posting after the prompt.

## 10. Seven-day offline practice guide

```
Make me a 7-day offline practice guide for the JOB TITLE job at COMPANY. I have about 15 MINUTES a day. Write it as guide text for the ShapeShft Practice Guide Builder, all in one code block.
```

Then copy the text, open `ShapeShft-Practice-Guide-Builder.html` from the `2-Tools` folder, paste it in, click Preview and then Download guide. For a single session, ask for "a single offline practice session" instead. For a reference to review, ask for "a complete conversation reference".

## 11. Prepare for a specific interview

```
I have an interview for the JOB TITLE job at COMPANY on DATE. It is with NAME, JOB TITLE. Other stages I know about: LIST THEM, OR "NONE YET". Please help me prepare, organized by interview stage and person, and include questions I should ask.
```

Add anything you know: notes from earlier interviews, the interview format, what the recruiter told you.

## 12. Questions to ask the interviewer

```
Help me prepare questions to ask NAME, JOB TITLE, at COMPANY. Use my career preferences and what is still unknown about this job. Give me the two or three most important ones first, in words that are easy to say out loud.
```

## 13. After an interview

```
I just had an interview with NAME, JOB TITLE, at COMPANY. Please help me reflect. Ask me questions one at a time, and keep what they actually said separate from what I think it means. Here are my first notes: WRITE WHATEVER YOU REMEMBER.
```

## 14. Compare opportunities

```
Help me compare these opportunities using my own career preferences: LIST THE JOBS FROM MY JOB LIBRARY, OR PASTE DETAILS. Show what fits, what conflicts and what is still unknown for each. Do not score them. Tell me what I still need to find out.
```

## 15. Update my Practice Journal

```
I finished a practice session. Here is what happened: WHAT WENT WELL, WHERE I GOT STUCK, ANYTHING I REMEMBERED FOR THE FIRST TIME. Please check whether anything new should go into my Career Profile, then give me the complete updated practice-journal.md file.
```

## 16. Start a new chat without losing anything

```
I need to continue in a new chat. Please give me the complete updated versions of any of my ShapeShft files that changed in this conversation, and a short "where we left off" note I can paste into the new chat.
```

In the new chat, attach your newest files (or make sure they are in your project), then paste:

```
I am continuing my ShapeShft work. Here is where we left off: PASTE THE NOTE.
```
