# Setting up Claude

This is a one-time setup. It takes about 10 minutes. You need the unzipped ShapeShft folder (see START HERE).

Claude's menus change from time to time. The steps below describe where things usually are. If something looks different, ask Claude itself: paste the text from `1-AI-Setup/Project-Instructions.txt` into a new chat and say "Help me set up a project for this."

## 1. Create an account

1. Go to claude.ai in your web browser, or install the Claude app on your phone or computer.
2. Sign up with your email address. The free plan is enough to start.

## 2. Create a ShapeShft project

1. In Claude, find **Projects** (usually in the left sidebar on a computer, or in the menu on a phone).
2. Create a new project. Name it `ShapeShft`.
3. Find the project's **instructions** box. Open `1-AI-Setup/Project-Instructions.txt` from the ShapeShft folder, copy all the text, and paste it into the instructions box. Save.
4. Find the place to add files to the project (often called project knowledge or files). Add `1-AI-Setup/ShapeShft-AI-Instructions.md`.
5. If you already have career files (from an earlier session), add them too: `career-profile.md`, `job-library.md`, `practice-journal.md`. If you are new, skip this. You will make them together with Claude.

## 3. Check that it works

1. Start a new chat inside the ShapeShft project.
2. Type `ShapeShft check` and send it.
3. Claude should say it can see the ShapeShft instructions, and tell you which career files it can see.

If Claude says it cannot see the instructions, check that `ShapeShft-AI-Instructions.md` is in the project's files, and that you started the chat inside the project.

## 4. Start

In the same chat, copy a prompt from `4-Prompts/Starter-Prompts.md`. Most people start with prompt 2 (Career Discovery) or prompt 7 (Conversation Coaching).

## Saving your files with Claude

When Claude gives you an updated career file, it may appear as a downloadable file. Download it, save it in your `3-My-Files` folder (replace the old one), then replace the old copy in the project's files. If it appears as text in a box instead, copy the text into the file and save.

## Optional: ShapeShft skills

The `1-AI-Setup/Claude-Skills` folder has four optional skill files. You do not need them if you use the project. See `About-Claude-Skills.txt` in that folder.

## Without a project

Start a normal chat, attach `ShapeShft-AI-Instructions.md` and your career files, and send: "Please follow these ShapeShft instructions for this conversation." You will need to attach them again in each new chat.
