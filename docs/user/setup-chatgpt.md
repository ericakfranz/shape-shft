# Setting up ChatGPT

This is a one-time setup. It takes about 10 minutes. You need the unzipped ShapeShft folder (see START HERE).

ChatGPT's menus change from time to time. The steps below describe where things usually are. If something looks different, ask ChatGPT: "How do I create a project and add files to it?"

## 1. Create an account

1. Go to chatgpt.com in your web browser, or install the ChatGPT app.
2. Sign up. The free plan is enough to start.

## 2. Create a ShapeShft project

1. In ChatGPT, find **Projects** (usually in the left sidebar on a computer, or in the menu on a phone).
2. Create a new project. Name it `ShapeShft`.
3. Open the project's settings and find the **instructions** box. Open `1-AI-Setup/Project-Instructions.txt` from the ShapeShft folder, copy all the text, and paste it in. Save.
4. Add `1-AI-Setup/ShapeShft-AI-Instructions.md` to the project's files.
5. If you already have career files from an earlier session, add them too: `career-profile.md`, `job-library.md`, `practice-journal.md`.

Free accounts can keep 5 files in a project and upload 3 files a day (OpenAI's help pages, checked November 26, 2026). ShapeShft uses at most 4 project files. On your first day, upload `ShapeShft-AI-Instructions.md` and, if you have it, `career-profile.md`. Add the other files the next day. If you reach the daily upload limit, open the file on your device, copy all of its text, and paste it into the chat instead.

The free ChatGPT model works with about 27,000 tokens of text at once, and the ShapeShft instructions are about 21,000 tokens. ChatGPT can still use them, because it reads project files in parts, but in long chats it may miss a step. Start a new chat for each task, and if it skips something, say: "Please check the ShapeShft instructions for this step."

## 3. Check that it works

1. Start a new chat inside the ShapeShft project.
2. Type `ShapeShft check` and send it.
3. ChatGPT should say it can see the ShapeShft instructions, and tell you which career files it can see.

## 4. Start

In the same chat, copy a prompt from `4-Prompts/Starter-Prompts.md`. Most people start with prompt 2 (Career Discovery) or prompt 7 (Conversation Coaching).

## Saving your files with ChatGPT

When ChatGPT gives you an updated career file, it usually appears as text in a box. Use the box's copy button, open your file in `3-My-Files` with a text editor (Notepad on Windows, TextEdit on a Mac), select all the old text, paste, and save. Then replace the copy in the project's files. If ChatGPT offers a download link instead, download the file and save it in `3-My-Files`.

## Memory

ChatGPT may have a memory feature. ShapeShft does not rely on it. Your career files are the record, so you can change assistants or start over without losing anything. You can turn memory off in ChatGPT's settings if you prefer.

## Without a project

Start a normal chat, attach `ShapeShft-AI-Instructions.md` and your career files (or paste their text), and send: "Please follow these ShapeShft instructions for this conversation." You will need to do this again in each new chat.
