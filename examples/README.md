# ShapeShft examples

Everything in these examples is fictional. The people, employers, schools, towns, job postings, phone numbers (all use 555) and email addresses (all use example.com) were made up for ShapeShft. Any resemblance to real people or organizations is accidental.

Use these examples to see what ShapeShft files and results look like. Do not copy facts from them into your own files.

## Morgan Ellery: shift supervisor moving up to operations manager

Morgan worked 14 years at one distribution center until it closed. Morgan has not interviewed in years and finds it hard to talk about results.

| File | What it shows |
|---|---|
| `morgan-ellery/career-profile.md` | A Career Profile after a few sessions, with tags, a story bank and a "do not claim" list |
| `morgan-ellery/job-library.md` | A Job Library with a full posting, alignment notes, interview stages and notes from a recruiter call |
| `morgan-ellery/practice-journal.md` | A Practice Journal with settings, a session log and interview reflections |
| `morgan-ellery/application-larkspur-operations-manager.json` | A complete resume and cover letter for the Resume Workbench. Load it in the Load tab to try the Workbench |
| `morgan-ellery/guide-single-session.html` | A guided 15 to 20 minute spoken practice session (open in a browser) |
| `morgan-ellery/guide-7-day.html` | A 7-day practice guide that reduces support over the week |
| `morgan-ellery/guide-interview-larkspur.html` | Interview preparation organized by interviewer, with questions to ask |
| `*.txt` files | The guide text the AI coach wrote. The Practice Guide Builder turned each one into the `.html` file |

## Teresa Halvorsen: HVAC technician applying for an internal promotion

Teresa is a lead technician applying to become Service Manager at the same company. This example shows a trade, a current job ("Present"), an internal posting, Template 2, and an Independent-level reference guide.

| File | What it shows |
|---|---|
| `teresa-halvorsen/career-profile.md` | A shorter Career Profile |
| `teresa-halvorsen/job-library.md` | An internal posting with an on-call question to investigate |
| `teresa-halvorsen/application-kestrel-service-manager.json` | Resume and short letter in Template 2 |
| `teresa-halvorsen/guide-conversation-reference.html` | A conversation reference with story cues, angles and unprepared practice |
